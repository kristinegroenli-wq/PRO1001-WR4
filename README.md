# PRO1001-WR4
PRO1001 Work requirement 4 - Product Ratings Dashboard

In this work requirement I used the highchart assist (AI tool) to help me figure out how to 
write the code for the function that counts and adds the products in the specified ranges. 
When I started working on the assignment, my initial plan was to make two charts for top rated products and ratings distribution. The highchart assist tool provided examples of how the js code could look, so I started using the examples as a placeholder for my final code. It was a great way to see how the charts would look on the page, and I could start making the HTML and CSS to see how it would look. I quickly figured out that I needed to do something simpler than rating distribution and top rated products, because the code was to complex for my knowledge level. I tried to use copilot to take me through some code examples, but I still had a hard time understanding how the code worked. So I ended up with two much simpler charts, but learning a lot in the process.
