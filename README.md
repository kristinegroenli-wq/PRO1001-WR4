# PRO1001-WR4
PRO1001 Work requirement 4 - Product Ratings Dashboard

In this work requirement I used the highchart assist (AI tool) to help me figure out how to 
write the code for the function that counts and adds the products in the specified ranges. 
When I started working on the assignment, my initial plan was to make two charts for top rated products and ratings distribution. The highchart assist tool provided examples of how it could be done, but I quickly figured out that I needed to do something simpler so that I could fully understand what the code was doing. So I ended up with two much simpler charts, but learning a lot in the process.
